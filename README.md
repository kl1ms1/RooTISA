# RooTISA Launcher

Крошечный домашний лаунчер (home screen) для слабых Android-телефонов —
сделан под **XS11 / MTK6580, экран 240×432, ~512 МБ–1 ГБ RAM, Android 8.1**.

Это **не прошивка** и не root: Android остаётся на месте. Лаунчер ставится как
домашний экран по умолчанию, и телефон запускает эту оболочку вместо стоковой.

## Возможности (v2)
- **Горизонтальные страницы** — иконки листаются вбок, по страницам (как на iOS),
  с точками-индикатором; свайп между страницами со «снапом».
- **Squircle-иконки** — скруглённые плитки в стиле Apple (маска в рантайме, без блюра).
- **TWEAKS** (⚙ на главном) — акцентный цвет, число колонок (3/4), подписи вкл/выкл,
  форма иконок (squircle/оригинал), возврат скрытых приложений, назначение лаунчером.
- **Кастомизация приложений** — долгий тап по иконке: переименовать, поставить свою
  картинку-иконку, сбросить иконку, скрыть, открыть «О приложении».
- **Лёгкость** — чистый framework API, **без AndroidX, без прав, без сети и без
  фоновых служб** → APK ~28 КБ, телефон не греется и ничего не блокирует Play Protect.

## Чего приложение НЕ делает (и не может)
- Не заменяет Android и не является прошивкой (под XS11 кастомной ROM нет — нет
  исходников ядра/vendor-блобов). Максимум — быть домашним экраном.
- Не делает root/jailbreak-твики: это требует root, недоступного на этом телефоне;
  APK не может менять систему. TWEAKS меняет только нашу оболочку.
- Не перехватывает системные жесты/переключение между уже открытыми приложениями
  (этим управляет ОС, не лаунчер) и не меняет внутренний вид чужих программ.

## Структура
```
launcher/
  AndroidManifest.xml            HOME + DEFAULT + LAUNCHER, без прав
  src/com/rootisa/launcher/
    MainActivity.java            paged home, плитки, кастомизация
    PagedHome.java               горизонтальный скролл со снапом по страницам
    TweaksActivity.java          экран TWEAKS
    Prefs.java                   настройки (SharedPreferences)
    IconTools.java               squircle-маска, загрузка своих иконок
    AppItem.java                 модель приложения
  res/                           строки, тема (Holo.NoActionBar), vector-иконка
  build.sh                       сборка APK без Gradle
```

## Сборка (без Android Studio / Gradle)
Нужны: `aapt`, `ecj`, `zipalign`, `apksigner` (из apt) + `android.jar` (API 27) и
`dx.jar` в `~/android-tools/`.
```bash
cd launcher
./build.sh        # -> build/RooTISA.apk
```
Конвейер: `aapt` → `ecj -1.6` (Java 6 байткод, т.к. легаси `dx 1.7` не читает новее)
→ `dx` → `aapt add` → `zipalign` → `apksigner` (v1+v2, min-sdk 16).

## Установка на телефон
```bash
adb install -r build/RooTISA.apk
```
Или скинуть APK на телефон (Bluetooth / кабель / облако) и открыть, разрешив
установку из неизвестных источников. Затем «домой» → выбрать **RooTISA → Всегда**.

Вернуть стоковый лаунчер: Настройки → Приложения → RooTISA → «по умолчанию» →
очистить, либо удалить APK.
