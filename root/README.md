# RooTISA Root — рут XS11 (MTK6580) через Magisk + ПК

Настоящий аналог jailbreak на Android: Android остаётся, но ты получаешь `su`
(полный доступ к системе) → системные твики, удаление любого хлама, Xposed-модули.

> ⚠️ **Риск кирпича реален.** Делай только осознанно. Главная страховка —
> держать ПОЛНУЮ стоковую прошивку: ей всегда можно «перезалить» телефон обратно.
> Рут = прошивка только раздела **boot**, остальное не трогаем.

---

## Что понадобится (всё на ПК, Windows проще всего)
1. **USB-кабель** и заряженный телефон (>50%).
2. **Драйверы MediaTek** — «MTK USB VCOM / Preloader drivers» (чтобы ПК видел телефон в режиме preloader).
3. **SP Flash Tool** (v5.x) — утилита прошивки MTK.
4. **Стоковая прошивка XS11 MTK6580** — в ней нужны файл **scatter** (`MT6580_...scatter.txt`) и **boot.img**.
   - Ищи на **4PDA** / форумах по запросу «XS11 MTK6580 прошивка» + по своему **«Номер сборки»** (Настройки → О телефоне).
   - Если не находишь — спроси у продавца (OZON/AliExpress), откуда брал; иногда дают ссылку на firmware.
   - Это самый сложный шаг: **без правильной прошивки дальше нельзя** (и именно она же — страховка от кирпича).
5. **Magisk** (APK) — приложение, которое патчит boot.img.
   - С GitHub `topjohnwu/Magisk` (в РФ GitHub бывает закрыт — качай на ПК и перекинь на телефон, как ставил RooTISA).

## Шаги

### 1. Подготовка телефона
- Настройки → «О телефоне» → 7 раз тап по «Номер сборки» → включатся «Для разработчиков».
- «Для разработчиков» → включить **Отладка по USB** и, если есть, **Заводская разблокировка (OEM unlocking)**.

### 2. Получить boot.img
Из стоковой прошивки возьми файл `boot.img`.

### 3. Пропатчить boot.img через Magisk (на телефоне)
- Установи Magisk (APK).
- Закинь `boot.img` в память телефона.
- Magisk → **Установить → Выбрать и пропатчить файл** → укажи `boot.img`.
- Получишь `magisk_patched_xxxx.img` (обычно в папке Download). Перекинь его на ПК.

### 4. Прошить пропатченный boot через SP Flash Tool (на ПК)
- Запусти **SP Flash Tool**.
- **Scatter-loading file** → выбери `scatter.txt` из стоковой прошивки.
- Режим вверху: **Download Only** (НЕ «Format All + Download»!).
- В списке разделов **сними все галочки**, оставь только **boot**.
- В строке `boot` замени путь на свой `magisk_patched_xxxx.img` (двойной клик по Location).
- Нажми **Download** (зелёная стрелка).
- **Выключи телефон**, подключи кабелем (SP Flash Tool сам поймает его в preloader).
- Дождись зелёной галочки «Download OK».

### 5. Готово
- Отключи, включи телефон. Открой Magisk — он покажет, что рут установлен.
- Проверка: любое рут-приложение запросит доступ, Magisk выдаст права.

---

## Если бутлуп / не включается
Не паникуй — boot легко вернуть:
- В SP Flash Tool так же в **Download Only** выбери **только boot** → укажи **стоковый** `boot.img` → Download. Телефон снова загрузится.
- Если совсем плохо — полная перезаливка стока: scatter + «Download Only», все разделы стоковые. (Поэтому полная прошивка = обязательная страховка.)

## Чего НЕ делать
- ❌ Не ставить «Format All + Download» без крайней нужды — сотрёт всё.
- ❌ Не флешить **preloader** от другого телефона — это главный источник «жёсткого» кирпича.
- ❌ Не брать прошивку от другой модели — только XS11 MTK6580.

---

## После рута
Скажи — добавлю в приложение RooTISA раздел **ROOT**: кнопки, которые через `su`
делают системные твики (анимации системно в ноль, смена DPI, чистка фона,
удаление системного хлама). Тогда «наш рут» = пульт управления прямо в оболочке.
