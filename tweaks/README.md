# RooTISA Tweaks (ADB) — ускорение XS11 без рута

Безопасный, **обратимый** набор твиков для слабого телефона (XS11 / MTK6580).
Всё делается через **ADB с компьютера** — рут и прошивка НЕ нужны, кирпич
исключён (любой твик откатывается `restore.sh`).

## Что это даёт
- Отключение/ускорение анимаций → интерфейс ощущается заметно быстрее.
- Чистка фонового мусора и лишних системных приложений (по твоему выбору).
- Необязательная подстройка плотности экрана.

## Что нужно
1. **Компьютер** (Windows / Mac / Linux) и **USB-кабель**.
2. На XS11 включить **Отладку по USB**:
   - Настройки → «О телефоне» → 7 раз тапнуть по «Номер сборки» → включится «Для разработчиков».
   - Настройки → «Для разработчиков» → включить **Отладка по USB**.
3. Установить **ADB** (platform-tools):
   - Windows: распаковать SDK Platform-Tools, открыть в папке cmd.
   - Mac: `brew install android-platform-tools`
   - Linux: `sudo apt install adb`
4. Подключить телефон кабелем, на телефоне разрешить отладку (всплывёт запрос).
   Проверка: `adb devices` — должно показать устройство.

## Запуск
```bash
# ускорить
bash speedup.sh          # Linux/Mac
speedup.bat              # Windows (двойной клик)

# откатить всё обратно
bash restore.sh
```

## Чистка мусора (debloat) — вручную и безопасно
Удаление «для пользователя 0» **обратимо** (приложение остаётся в системе,
восстанавливается одной командой), поэтому кирпича не будет.

```bash
# посмотреть все пакеты:
adb shell pm list packages

# удалить конкретный (пример — замени на нужный):
adb shell pm uninstall --user 0 <имя.пакета>

# вернуть обратно:
adb shell cmd package install-existing <имя.пакета>
```

⚠️ **Не трогай**: `com.google.android.gms`, `com.android.vending`,
`com.android.systemui`, `com.rootisa.launcher` и всё, в чём не уверен —
это ядро системы. Удаляй только явный хлам (игры-промо, лишние браузеры и т.п.).

## Хочешь дальше — рут (настоящий «jailbreak»)
Рут через **Magisk** открывает системные твики и удаление любого хлама.
Нужны: стоковая прошивка/boot.img для XS11 MTK6580 (ищется на 4PDA по модели),
Magisk для патча boot.img и **SP Flash Tool** для прошивки. Есть риск кирпича,
поэтому только осознанно и с резервной копией стока. Скажи — распишу по шагам.
